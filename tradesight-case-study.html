"TradeSight AI" — Financial Analytics

Designing an elegant, high-performance brand identity and dashboard system for modern asset forecasting.

Brand Identity Python Backend Data Analysis FinTech UX

The Challenge

Financial trading dashboards are typically cluttered, confusing, and dry. Most platforms use rigid tables and clinical default color combinations (standard dark blues, greys, and reds) that lack personality and can intimidate newer retail traders.

Our team set out to build **TradeSight AI** for the **Yukti Hackathon**—an AI-driven market analysis engine that translates live news and price feeds into a premium, curated visual brand. The challenge was combining complex data charts with an premium, warm chocolate-and-gold luxury aesthetic.

Brand Identity & Aesthetic

We avoided the typical generic "tech blue" color palette. Instead, we developed a system based on premium gold highlights and dark warm chocolate tones. Gold conveys prosperity and premium quality, while the deep chocolate provides soft contrast that feels high-end, elegant, and comfortable to view over long periods.

Key Features

  • AI Sentiment Analysis: Uses Python natural language processing (NLP) to scan market articles and assign real-time positive/negative scores to index components.
  • Predictive Candlestick Charts: Machine learning forecasts future price bands, drawing clean indicator overlays directly onto the chart.
  • Luxury Dashboard Design: Minimal borders, generous spacing, and custom font sets (Inter paired with elegant serif quotes) to create an editorial feel.

Technical Implementation

The backend was written in Python to fetch real-time financial datasets. We used standard prediction models to run analysis. The frontend dashboard was built using pure, clean responsive styles to keep load speeds ultra-fast.
